# SHAMSIDIN BUSINESS PRO

Android WebView wrapper for the supplied offline HTML app.

## Build on GitHub
1. Create a GitHub repository and upload the contents of this folder to the repository root.
2. Open the **Actions** tab and enable workflows if GitHub asks.
3. Run **Build Android APK** using **Run workflow**, or push to `main`.
4. Open the completed workflow run and download the `SHAMSIDIN-BUSINESS-PRO-APK` artifact.
5. Extract the ZIP artifact; it contains `app-debug.apk`.

This is a debug APK for personal testing. The HTML app stores data locally in WebView storage; export backups regularly. The four-digit PIN in the HTML prototype is not strong encryption.
